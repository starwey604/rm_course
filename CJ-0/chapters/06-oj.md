# 为什么这道题用 int 装得下？

<div class="l1-lead">P1001：输入两个整数 a、b，输出它们的和；−10⁹ ≤ a, b ≤ 10⁹<br>输入示例：1 2    输出示例：3；输出中不添加提示语</div>
<div class="l1-numbers"><div><span>本题的最大和</span><b>2000000000</b></div><div><span>32 位 int 的最大值</span><b>2147483647</b></div></div><div class="l1-lead">2000000000 &lt; 2147483647，最大和没有超出上限</div>
<div class="l1-lead">下限也够：−2000000000 &gt; −2147483648</div>
<div class="l1-bottom">所以本题可用 int；范围变大时，要重新检查类型是否装得下</div>

<div class="l1-columns">
<div>



