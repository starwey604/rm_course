## ISBN 与输入输出的具体教学处理

只以 P1055 题目给定的 ISBN-10 风格 `x-xxx-xxxxx-x` 为输入格式示例，不将该分组规则说成所有现实 ISBN 的通用规则。

预定核心示例：

```c
int group, publisher, book;
char check;
int matched = scanf("%d-%d-%d-%c",
                    &group, &publisher, &book, &check);
```

- 用格式串里的字面 '-' 消费对应分隔符；它不是空白。
- 展示继续直接用 %d 读下一段时，'-' 可能被解释为负号；不要告诉学生“scanf 会自动跳过连字符”。
- 最后一位使用 %c，兼容数字字符与 X。
- 成功读入四个变量时 matched 为 4；不把三个分隔符算进去。
- 说明 %c 不自动跳过空白，并与上一节 `" %c"` 的用法关联；题目保证格式时，不要求实现通用输入纠错。
- 用 `printf("%d-%03d-%05d-%c\n", ...)` 演示题目固定宽度的补零还原。
- 到字符串模块再展示 `char isbn[14]; scanf("%13s", isbn);`，解释为什么可容纳 13 个可见字符和一个结束符。
- ISBN 校验算法不占开场时间。P1055 完整题只作为学有余力者的综合选做，需要额外处理字符转数字、加权和、模 11 与 X。

## C / C++ 输出扩展页

同一输入数据：`int sum = 6; double avg = 2.0;`

同一目标输出：`sum=6, avg=2.00`，随后换行。

| 方式 | 预定示例 | 页面提示 |
| --- | --- | --- |
| C printf | `printf("sum=%d, avg=%.2f\n", sum, avg);` | `<stdio.h>`，格式说明符与参数类型匹配 |
| C++ cout | `std::cout << "sum=" << sum << ", avg=" << std::fixed << std::setprecision(2) << avg << '\n';` | `<iostream>` / `<iomanip>`，流式输出与精度设置 |
| C++23 std::println | `std::println("sum={}, avg={:.2f}", sum, avg);` | `<print>`，{} 格式、自动换行；需要标准库支持 |

三行依次出现，底部共享一个输出结果。不扩展为 C++ 语法课，不要求学生更换课堂 C 工程或升级工具链。说明其采用与 {fmt} 相近的格式语法，避免把标准库 std::println 和第三方 fmt::println 混写。
