## 1. P5719 分类平均 · <https://www.luogu.com.cn/problem/P5719>

把 1 到 n 分成「能被 k 整除」和「不能被 k 整除」两组，各求平均数，保留一位小数。
要点：两组各一个计数器和一个和，循环结束后分别相除。
易错：`sum / cnt` 是整数除法，要写 `(double)sum / cnt`；计数器漏加会让平均值偏大。
样例：`100 16` → `56.0 50.1`

## 2. P5720 一尺之棰 · <https://www.luogu.com.cn/problem/P5720>

求长度第一次变成 1 是第几天，每天整除 2。
要点：`while (a > 1) { a /= 2; day++; }`，天数从第 1 天算。
易错：先判断还是先操作，决定天数差 1；a 最大 10⁹，用 int 够。
样例：`100` → `7`

## 3. P1427 小鱼的数字游戏 · <https://www.luogu.com.cn/problem/P1427>

读一串整数，遇到 0 停止，再倒着输出。
要点：读到 0 之前先存进数组，0 不计入有效个数。
易错：倒序从 `cnt - 1` 开始；末尾那个 0 不能输出；结尾不要多一个空格。
样例：`3 65 23 5 34 1 30 0` → `30 1 34 5 23 65 3`

## 4. P5733 自动修正 · <https://www.luogu.com.cn/problem/P5733>

把所有小写字母改成大写，其余字符保留。
要点：遍历字符，落在 `'a'` 到 `'z'` 之间就减 32。
易错：数字、标点、已有的大写都要原样保留；输出整串别漏结束符。
样例：`Luogu4!` → `LUOGU4!`

## 5. P5721 数字直角三角形 · <https://www.luogu.com.cn/problem/P5721>

n 行直角三角形，从 1 开始连续编号，每个数占两位、不足补 0。
要点：外层管行（共 n 行），内层管这一行的个数（第 i 行 n-i+1 个）；用一个计数器跨行连续递增。
易错：`%02d` 是补零不是空格；数字之间不加空格；每行结束要换行。
样例：`5` → `0102030405 / 06070809 / 101112 / 1314 / 15`

## 6. P1428 小鱼比可爱 · <https://www.luogu.com.cn/problem/P1428>

每条鱼只数左边比它小的鱼有几条。
要点：对每个 i，再扫一遍 0 到 i-1 的元素；两层循环，内层范围随外层变化。
易错：只往左看，不看右边；相等不算；输出 n 个计数，顺序与原数组一致。
样例：`6 / 4 3 0 5 1 2` → `0 0 0 3 1 2`

## 7. P1047 校门外的树 · <https://www.luogu.com.cn/problem/P1047>

0 到 L 每个位置一棵树，按区间移除（区间可能重叠），求剩几棵。
要点：开 `flag[L + 1]` 记录状态，遍历每个区间把 `[u, v]` 标为已移除，最后数仍标记为「在」的位置。
易错：一共有 `L + 1` 个位置，不是 L 个；区间两端都要移走；重叠区间重复标记即可，不用特判。
样例：`500 3 / 150 300 / 100 200 / 470 471` → `298`

## 8. B2111 基因相关性 · <https://www.luogu.com.cn/problem/B2111>

两条等长 DNA 序列逐位比较，相同比例达到阈值输出 `yes`。
要点：一次循环同时看两条串的同一位，统计相同个数再除以长度。
易错：比例要按浮点数算；阈值用 double 读；输出小写 `yes` / `no`。

## 9. B2112 石头剪子布 · <https://www.luogu.com.cn/problem/B2112>

N 局猜拳，逐局判断谁赢。
要点：用 `strcmp` 判断三种单词，再列出胜负组合。
易错：单词区分大小写，`Rock` 不是 `rock`；平局输出 `Tie`；每局一行。
样例：`3 / Rock Scissors / Paper Paper / Rock Paper` → `Player1 / Tie / Player2`

## 10. P1980 计数问题 · <https://www.luogu.com.cn/problem/P1980>

统计 1 到 n 的所有整数里，数字 x 一共出现了多少次。
要点：外层 1 到 n，内层对每个数拆位——`while (t > 0) { if (t % 10 == x) cnt++; t /= 10; }`。
易错：拆位法天然不统计前导零，正好符合题目要求；x 可能是 0，别把「0 出现」写成「数里有 0 位」的特判；n 到 10⁶，双重循环约 7×10⁶ 次，能过。
样例：`11 1` → `4`
