<div class="eyebrow">01 · 把连字符写进格式串</div>

# 数字交给 %d，连字符原样匹配

<div class="two-col"><div>

```c
int group, publisher, book;
char check;
scanf("%d-%d-%d-%c",
      &group, &publisher,
      &book, &check);
```

</div><div>

<div class="label">输入 0-670-82162-4 后</div>
<div class="large mono">0　670　82162　'4'</div>
<p v-click class="spaced">三个 <strong>-</strong> 被匹配掉，<br>不用为它们准备变量。</p>
<p v-click>最后一位也可能是 <strong>X</strong>，<br>所以用 <code>%c</code>。</p>

</div></div>

<!--
约2分钟。匹配字面连字符本身不算一次赋值，成功应返回4。完整程序检查返回值，课上可追问“传来的数据不完整，怎样发现？”不把真实串口协议简化成直接scanf。
%c不会自动跳过空白，需要跳过前导空白时格式可写" %c"；本页不要同时引入这个次要分支，学生提问时再补充。不要随意在scanf格式串末尾加换行。

<div class="eyebrow">01 · printf 的宽度</div>

# 读成整数后，前导零去哪了？

<div class="teaching-anchor">换一本书：<code>0-001-00042-X</code>。用 <code>%d</code> 读入两个分组后，<br><code>001</code> 变成整数 <code>1</code>，<code>00042</code> 变成整数 <code>42</code>。打印时怎样补回前导零？</div>

<div class="two-col"><div>

```c
// 两个分组读成整数后的值
int publisher = 1, book = 42;
printf("%d %d\n",
       publisher, book);
```

<div v-click="1" class="output spaced">1 42</div>

</div><div>

```c
printf("%03d %05d\n",
       publisher, book);
```

<div v-click="2" class="output spaced">001 00042</div>

</div></div>

<div class="teaching-anchor spaced"><code>%03d</code>：至少占 3 位，不足补 0；<code>%05d</code> 同理，至少占 5 位。</div>

<!--
约2分钟。换用0-001-00042-X，与之前的书号区分；本页只关注两个分组的前导零。宽度是最小输出宽度，不会截断更长的数。题目固定分组时可用%d-%03d-%05d-%c还原。
-->

<div class="eyebrow">拓展一页 · C 与 C++ 的输出</div>

# 同一个结果，三种写法

<div class="tiny-note mono">int sum = 6;　double avg = 2.0;</div>

<div class="comparison-row" v-click="1"><div class="label">C · printf：<strong>格式符要与类型对上</strong></div>

```c
printf("sum=%d, avg=%.2f\n", sum, avg);
```

</div>
<div class="comparison-row" v-click="2"><div class="label">C++ · cout：<strong>按类型输出，控制小数位要多写几段</strong></div>

```cpp
std::cout << "sum=" << sum << ", avg="
          << std::fixed << std::setprecision(2) << avg << '\n';
```

</div>
<div class="comparison-row" v-click="3"><div class="label">C++23 · println：<strong>{} 按类型填入，{:.2f} 保留两位小数</strong></div>

```cpp
std::println("sum={}, avg={:.2f}", sum, avg);
```

</div>
<div class="output spaced" v-click="1">sum=6, avg=2.00</div>
