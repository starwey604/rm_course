<div class="eyebrow">01 · 输入细节</div>

# 分隔符不会自动被跳过

<div class="two-col"><div>

```c
int group, publisher, book;
char check;

scanf("%d-%d-%d-%c",
      &group, &publisher,
      &book, &check);
```

</div><div>

<v-clicks>

- 格式中的 **-** 与输入中的 **-** 匹配。
- 若连续用 `%d`，`-670` 可能被读成负整数。
- `%c` 不自动跳过空白；需要跳过前导空白时可写 `" %c"`。

</v-clicks>

</div></div>

<div class="note">这里输入格式由题目保证。完整实现仍应检查 <code>scanf(...) == 4</code>。</div>

<!--
约2分钟。空白匹配与字面字符匹配不同。不要在scanf格式串末尾随意加换行。%c在匹配连字符后读取校验字符。
依据：https://learn.microsoft.com/en-us/cpp/c-runtime-library/scanf-type-field-characters
-->

<div class="eyebrow">01 · printf 的宽度</div>

# 读成整数后，前导零去哪了？

<div class="two-col"><div>

```c
// 固定宽度的格式练习
int publisher = 1, book = 42;
printf("%d %d\n",
       publisher, book);
```

<div v-click="1" class="output spaced">1 42</div>

</div><div>

```c
printf("%03d %05d\n",
       publisher, book);
```

<div v-click="2" class="output spaced">001 00042</div>

</div></div>

<div class="note"><code>%03d</code>：至少占 3 位，不足时补 0。保留完整原文的方法，等字符串部分再看。</div>

<!--
约2分钟。数字只用于格式练习，不声称构成校验正确的ISBN。宽度是最小输出宽度，不会截断更长的数。题目固定分组时可用%d-%03d-%05d-%c还原。
-->

<div class="eyebrow">拓展一页 · C 与 C++ 的输出</div>

# 同一个结果，三种写法

<div class="tiny-note mono">int sum = 6;　double avg = 2.0;</div>

<div class="comparison-row" v-click="1"><div class="label">C · &lt;stdio.h&gt;</div>

```c
printf("sum=%d, avg=%.2f\n", sum, avg);
```

</div>
<div class="comparison-row" v-click="2"><div class="label">C++ · &lt;iostream&gt; 与 &lt;iomanip&gt;</div>

```cpp
std::cout << "sum=" << sum << ", avg="
          << std::fixed << std::setprecision(2) << avg << '\n';
```

</div>
<div class="comparison-row" v-click="3"><div class="label">C++23 · &lt;print&gt; · {} 格式，自动换行</div>

```cpp
std::println("sum={}, avg={:.2f}", sum, avg);
```

</div>
<div class="output spaced" v-click="1">sum=6, avg=2.00</div>
