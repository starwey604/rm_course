# CJ-2 讲师速查：函数、指针与结构体

在仓库根目录运行 `pnpm dev:cj-2`，打开 [本地课件](http://localhost:3032/cj-2/)。点击正文或按右方向键揭示，左方向键退回上一步。各页的讲师备注有时间和提问建议。

| 分钟 | 课堂动作 |
| --- | --- |
| 00–34 | 抽出 `clamp_speed`；带做 P5737；用滤波链、PID 和四轮解算讲纯计算的分工 |
| 34–75 | 比较值副本和地址副本；填空交换；用四轮限幅回访数组与 `scanf`；看 Zephyr 怎样换驱动 |
| 75–85 | 休息；助教用速度格、地址和指针格答疑 |
| 85–117 | 打包电机数据；沿地址改成员；带做 P5742；对比 C 的对象式调用和 C++ 成员函数 |
| 117–120 | 快问快答：填一处实参，把第三轮的目标转速清零 |

主讲 38 页，另有 1 页 P5733 备用题。滤波流水线、Zephyr 驱动和面向对象只做读代码和预测；课堂动手仍用 C。

## 练习与演示

- 开课前准备 [底盘演示](examples/chassis.c)，用 C 编译器运行。它依次输出限幅、清零、交换、更新结构体和数组的结果。
- 发给学生 [P5737 骨架](examples/p5737_fill.txt) 和 [P5742 骨架](examples/p5742_fill.txt)。分别保存为 `.c`，把带编号的占位值替换成自己的表达式，再编译或提交。讲评后再发 [P5737 完整实现](examples/p5737.c) 和 [P5742 完整实现](examples/p5742.c)。
- 打印讲义用 `pnpm export -- cj-2`。三段内存动画在 PDF 中各保留一张过程表，挖空和答案仍分开。
